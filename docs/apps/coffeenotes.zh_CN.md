# CoffeeNotes 咖啡手记

CoffeeNotes 是 AI Passport 上的中文咖啡日历与手冲参考应用。使用三个物理按键、
240 x 320 竖屏和既有 BSP，使用咖啡棕、抹茶绿、海盐蓝和深夜黑四套原创配色，不使用硬件测试菜单。

## 功能与按键

首页显示今日、本周或本月杯数和对应日期范围，以及四个入口。默认选中记录一杯；
按上选择统计卡片，确定循环切换范围并保存。本周按周一至周日，统计不会改变日期或记录。
上/下选择，确定打开；其余页面长按确定返回或取消。双击按一次选择处理，不会一次生成两条记录。

| 页面 | 操作和行为 |
| --- | --- |
| 记录一杯 | 上/下选择手冲、意式、美式、拿铁、冷萃或其他，确定保存。长按上修改日期时间，长按确定取消。保存前必须联网校时或人工确认日期。 |
| 咖啡日历 | 上/下移动一天，长按上/下切换月份；背景色阶表示 0、1、2、3+ 杯，底部显示图例；选中描边保留饮用色阶；确定进入当天。周一为每周起始。 |
| 每日记录 | 最近保存的记录在前；上/下滚动所有记录及新增入口；确定查看明细或为该日期新增。删除需单独确认，默认选中保留。星号表示人工确认的时间。 |
| 冲煮手册 | 清爽、醇厚、冰手冲三种起点配方；确定查看参数和累计注水步骤；上/下选择开始计时或调整参数。 |
| 调整参数 | 上/下选择项目，确定进入/完成编辑，上/下调整数值；选择保存并确定，长按确定放弃修改。 |
| 冲煮计时 | 确定暂停/继续，上键完成并生成带实际时长的手冲记录草稿；长按确定取消，不新增记录。使用单调时间，联网或手动校时不会改变计时。 |
| 配色风格 | 设置中进入；上/下实时预览四套配色，确定保存，长按确定取消并恢复原配色。 |
| 日期时间 | 上/下选择年、月、日、时、分、确认；确定进入/退出数值编辑；确认应用手动日期或记录更正；长按确定恢复先前草稿。 |
| 配网 | 确定开启/重试，长按确定关闭临时热点并返回。忘记网络需单独确认，默认取消，不影响咖啡数据。 |

60 秒无操作后完全关闭背光；冲煮计时中（含暂停）和配网时保持亮屏。首次按键整次手势
只恢复 85% 亮度，不保存、导航或取消。熄屏时应用和时钟仍继续运行，不进入设备休眠。电量位于右上角，不可用时显示 `--`。

## Wi-Fi 与北京时间

在设置中选择配置 Wi-Fi。设备生成临时 WPA2 热点 `CoffeeNotes-xxxx`，随机八位密码
显示在屏幕上。手机连接热点，手动在浏览器打开 `http://192.168.4.1`，填写 2.4 GHz 路由器的
名称和密码，无需配套应用。手机提示热点无互联网时仍应保持连接。未实现自动弹出的强制门户。
开放网络可留空密码，WPA2 密码为 8-63 字节。

表单包含会话令牌、512 字节请求限制和严格解码；通过队列交给网络任务，验证目标网络
获取 IP 后才保存。密码错误或路由器不可用时保留原有网络。网页区分正在验证和已验证保存。
成功、取消或五分钟到期后关闭热点与 HTTP；停止或模式切换失败时保留清理状态重试，避免热点
在普通重连中悄然重新启动。

已保存网络使用有限次数重试和指数退避。SNTP 服务器为 `pool.ntp.org` 和 `ntp.aliyun.com`，
时区 `CST-8`（UTC+8）。网络关联不等于时间有效，只有真实的 2020-2099 年 SNTP 结果才认可。
校时回调携带单调时间顺序，较早的联网校时不会把较晚的手动设置误标为联网时间。

冷启动时，最后保存日期或初始构建日期只是待确认草稿；联网校时前需手动确认日期时间才能保存。
持续上电时，已确认的手动时钟正常递进；完全断电后需再确认或等待 SNTP，不假设存在后备实时时钟。
首次校时发生在未确认记录草稿打开期间时，更新其日期时间。

Wi-Fi 凭据本地保存于独立的 `coffee_wifi` NVS 命名空间，当前基线未启用 Flash/NVS 加密。
不记录密码日志，不在固件源码嵌入路由器凭据。不使用云端咖啡账户、语音、豆名键盘或外接硬件。

## 参考配方与存储

以下为可调整的冲煮起点，不是适用于所有咖啡豆的固定标准：

| 配方 | 咖啡粉 | 热水 | 水温 | 目标时长 | 额外冰块 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 清爽 | 15 g | 240 ml | 92 C | 2:30 | 无 |
| 醇厚 | 20 g | 300 ml | 94 C | 3:00 | 无 |
| 冰手冲 | 15 g | 150 ml | 91 C | 2:00 | 100 g |

可调整范围：粉量 5-40 g、热水 50-600 ml、温度 70-99 C、时长 60-360 秒。
四段从目标时间的 0%、20%、45%、70% 开始，提示累计注水 20%、45%、75%、100%。
冰手冲的冰量固定为 100 g。计时可超过目标，显示最多 99:59；完成后仍需确认记录，不自动保存。
没有蜂鸣提醒。

最多保存 512 条咖啡类型、日期、分钟、可选配方与实际冲煮时长、人工日期标志；满容量拒绝
新增，由用户明确删除旧条目，不会静默淘汰记录。`coffee_notes/journal` 使用显式小端字段、
版本 1 和 CRC32，参数、日期设置及偏好共用该数据，Wi-Fi 单独存储。不在启动时清空 NVS；发现损坏
或读取失败时阻止写入，保留原始数据以供诊断。设置/提交失败后禁止继续写入直到重启，因为
NVS 可能已经写入新数据；重启加载实际存储结果。仅保存返回成功后界面显示成功。
首页范围切换和配色确认才写入偏好；主题预览、导航与计时刷新不写 Flash。
记录头第 14、15 字节分别保存统计范围及配色，保持原 version-1 布局及 CRC；旧版零值头
加载为今日统计和咖啡棕，不丢失已有记录与配方。非法偏好按损坏数据处理。保留默认分区表（24 KB NVS、PHY、factory 应用）。
